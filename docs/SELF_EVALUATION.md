진행으로 이어지는 하나의 사슬이 실제로 동작한다.

## 개선이 필요한 부분

**카메라 가림** — 정밀정렬 단계에서 작업자의 손이 대상을 덮으면 파지 실패.
현재는 재시도로 대응하며, 가림 예측·회피 시점 판단이 없다.

**동일 클래스 다중 개체** — 카메라별로 클래스당 검출 1개만 유지하므로,
같은 공구가 둘 이상이면 카메라마다 다른 개체를 골라 삼각측량이 어긋난다.

**AI 분석 지연** — 사진 판정에 6~9초. 일시적 API 실패 시 재시도까지 포함하면
작업자 체감이 길다.

**복합 발화 처리** — 한 문장에 요청이 둘이면 하나만 실행되고 나머지는 버려진다.
("확인해주고 다음 단계 알려줘" → 확인만 수행)

**대화 문맥 단절** — 시스템 답변이 대화 기억에 기록되지 않아, 이어지는 질문에서
직전에 자신이 한 말을 참조하지 못한다.

## 향후 발전 방향

**다중 개체 매칭** — 카메라별 후보를 복수 유지하고, 손가락 광선에 가장 가까운
조합을 선택해 같은 공구가 여러 개인 상황을 해결한다.

**단일 발화 다중 의도 분해** — 한 문장에서 의도를 순서대로 추출해 차례로
실행하고, 완료 후 하나의 답변으로 통합한다.

**공유 대화 기억** — 모든 답변을 기억에 기록하고 조립·검사 경로에도 전달해,
시스템 전체가 하나의 맥락 위에서 판단하게 한다.

**센서 융합 강화** — 카메라 간 신뢰도 가중과 가림 예측으로 실패를 사전 차단.

**작업 데이터 축적** — 행동 패턴과 실패 기록을 학습해 대응 공구·제품 범위를
넓히고 개인화된 제안으로 확장한다.

## 팀이 배운 것

개별 AI 모델의 정확도만큼이나 **로봇·카메라·네트워크·UI 사이의 안정적인 통합과
예외 상황 복구**가 중요하다.

**측정한 것만 믿는다.** 삼각측량마다 광선 간 최대 오차를 함께 계산해 기준을
넘으면 결과를 버리는 설계가, 그럴듯한 오답을 구조적으로 차단했다.

**애매하면 판단을 보류한다.** 두 공구가 4° 이내로 붙어 있으면 되묻고, 사진으로
판단이 안 되면 "확실하지 않다"고 답한다. 확신에 찬 오답이 작업자에게 가장 해롭다.

**상태를 바꾸는 결정은 규칙이, 표현은 LLM이 맡는다.** 로봇을 움직이고 작업
진행을 기록하는 판단은 결정론적 코드가 내려야 검증과 재현이 가능하다.

사람과 함께 움직이는 로봇에서는 빠른 동작보다 **안전하고 예측 가능한 동작**이
우선되어야 한다는 점을 경험했다.
